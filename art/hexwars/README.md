# Bearbeitbare Hexwars-Quellen

Originale Blender-Dateien des [übernommenen Modellbestands](../../public/assets/hexwars/README.md),
bytegleich aus Hexwars-Commit `777d4298569df9925915e5395968dffea83dd10f`.
Im Quellprojekt mit Blender 5.2 bearbeitet; einige Dateien sind komprimiert.

| Datei | Inhalt |
| --- | --- |
| `mech-rig.blend` | Getrennte mechanische Baugruppen und fünf NLA-Animationsclips |
| `railgun-animated.blend` | Vierbeinige Railgun mit sechs NLA-Animationsclips |
| `factory-source.blend` | Fabrik, Torsegmente und Produktionsmodule |
| `hoverbot.blend` | Bearbeitbarer Hover-Bot mit Materialien |
| `hq.blend` | HQ mit getrenntem Radar |
| `relay.blend` | Relais mit getrenntem Kern und Schüsseln |

Die Dateien sind zum späteren Bearbeiten abgelegt und werden nicht in den Web-Build
kopiert. Interne Textblöcke/Pfade bleiben wie im Quellprojekt; Autorenwerkzeuge und
Spielcode wurden nicht übernommen. [Herkunft](../../public/assets/hexwars/CREDITS.md)
und [genaue ursprüngliche Pfade](../../public/assets/hexwars/provenance.json).
