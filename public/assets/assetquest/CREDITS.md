# AssetQuest — free Forest Kit demo

Source: [Stylized Forest Kit](https://assetquest.itch.io/stylized-forest-kit), Asset Quest.
Downloaded on 2026-10-29 using the public **Download demo** button. No purchase.
Original archive: `Forest_Kit_AssetQuest_Itch_FREE_DEMO.zip`.
The included `Forest_Kit_License_DEMO.txt` is preserved as `LICENSE.txt`: CC0.

`forest-details.glb` contains eight selected demo models: Birch Tree 1,
Blackberry Bush 1b, Fern 1a, Forest Grass 1, Fly Agaric Group 1, Bay Bolete
Group 1, Tree Stump 1 and Woodruff Cluster 1. Converted from FBX with
`tools/import-decoration.py` in Blender 5.2. The shared foliage atlas is
converted from TGA to PNG at 1024² with its alpha channel; the original
palette texture is retained. Runtime cutout materials, grounded placement,
scale and shared instances adapt them to the courtyard.

The commercial full pack has not been purchased or included.
